# Segmentasi dan Pola Nilai Rumah di California: Analisis Eksploratif dengan PCA dan K-Means Clustering

Repositori ini memuat *notebook* kode analisis (`.ipynb`) dan laporan lengkap (`.pdf`) untuk **Tugas Individu dan Tes Tengah Semester (TTS)** mata kuliah **Analisis Data Eksploratif** (Program Studi Teknik Informatika, FTI UKSW). Proyek ini mengkaji faktor-faktor penentu harga properti serta memetakan segmentasi blok sensus menggunakan dataset **California Housing Prices**.
